# D-pay — درگاه پرداخت غیرمتمرکز Web3

وب‌سایت تک‌صفحه‌ای سینمایی D-pay، ساخته‌شده از ارائه‌ی `dpay_presentation-v3.pptx`
بر اساس هویت بصری Verexa (`Verexa Visual Identity.pdf`).

## هویت بصری پیاده‌سازی‌شده

| عنصر | مقدار |
|---|---|
| رنگ اصلی D-pay | `#07C8DA` (فیروزه‌ای — رنگ رسمی ساب‌برند D-pay) |
| پس‌زمینه | `#04070D` / `#0F172A` (سرمه‌ای تیره، مطابق ارائه) |
| رنگ‌های مکمل ارائه | `#38BDF8` ،`#10B981` ،`#F59E0B` |
| فونت فارسی | **Peyda** (هر ۹ وزن، فایل‌های `PEYDA-*.TTF` → `assets/fonts/*.woff2`) |
| فونت انگلیسی | **Montserrat** (متغیر، `assets/fonts/montserrat-var.woff2`) |

## ساختار

```
index.html              ← نقطه ورود سایت (کافی است همین فایل سرو شود)
assets/
  css/style.css         ← سیستم دیزاین کامل
  js/main.js            ← تعامل‌ها (بدون هیچ فریم‌ورک یا CDN)
  fonts/*.woff2         ← فونت‌های سابست‌شده هویت بصری
  img/hero-art.jpg      ← ویژوال هیرو
  img/favicon.svg       ← فاوآیکون
```

## اجرا

بدون نیاز به بیلد؛ فقط با یک سرور استاتیک:

```bash
python3 -m http.server 8080
# سپس باز کنید: http://localhost:8080
```

سایت کاملاً آفلاین و بدون وابستگی خارجی کار می‌کند (مناسب اتصال مستقیم
ریپازیتوری به Google AI Studio یا هر هاست استاتیک).

## نگاشت ارائه به سایت

| اسلاید | بخش سایت |
|---|---|
| ۱ — معرفی درگاه | Hero + آمار + تیicker |

| ۶ — سفر خریدار و پذیرنده | فلوی ۴ قدمی خریدار + داشبورد نمایشی پذیرنده با برداشت دستی |
