# D-pay — ارائهٔ تعاملی (جایگزین پاورپوینت)

وب‌سایت «ارائهٔ تعاملی» برای درگاه پرداخت غیرمتمرکز **D-pay**، ساخته‌شده کلمه‌به‌کلمه از
`dpay_presentation-v3.pptx` (۶ اسلاید) بر اساس هویت بصری Verexa.
به‌جای باز‌کردن فایل پاورپوینت، سایت را باز می‌کنید و با **اسکرول**، ارائه را می‌بینید.

## ساختار

```
index.html              ← نقطهٔ ورود (پردهٔ ۱: دک ۱۳ صحنه‌ای · پردهٔ ۲: ویدیو + بخش تعاملی)
assets/
  css/style.css         ← سیستم دیزاین کامل (RTL، موبایل‌فرست)
  css/ai.css            ← سبک FAQ + پنل دستیار هوشمند
  js/main.js            ← موتور دک + تعامل‌ها (بدون فریم‌ورک / بدون CDN)
  js/ai.js              ← سیستم مدیریت رفتار Gemini + گفت‌وگوی صوتی (Web Speech)
  css/yt.css            ← بخش کانال ویدیو + پنجرهٔ پخش شناور
  js/yt.js              ← پخش‌کنندهٔ داخلی یوتیوب (facade، پلی‌لیست، پنجرهٔ شناور)
  fonts/peyda-*.woff2   ← هر ۹ وزن Peyda، سابست‌شده از TTF‌های ریپو (هرکدام ~۱۸KB)
  fonts/montserrat-var.woff2 ← مونتسرات متغیر (wght 100–900)، سابست‌شده
  img/hero-art.jpg      ← هنر کاور/پایان ارائه
  img/favicon.svg       ← فاوآیکون
```

## پردهٔ ۱ — دک سینمایی

- استیج **sticky تمام‌صفحه** (`100svh`) روی ریل اسکرول ۱۴گامی؛ با اسکرول، **۱۳ صحنه**
  پشت‌سرهم فعال می‌شوند (هر صحنه = یک ایده از اسلایدها).
- ترنزیشن سینمایی `blur / scale / حرکت عمودی` + **نور جاروبی** (light-sweep) هنگام تعویض صحنه.
- کروم صحنه: شمارندهٔ «صحنهٔ ۰۱/۱۳» با اعداد فارسی، چیپ شمارهٔ اسلاید،
  **۶ تیکِ پرش** به اسلایدها، دکمهٔ قبلی/بعدی، نوار پیشرفت و راهنمای کیبورد.
- کیبورد: `← / →` (در RTL چپ = بعدی)، `PageUp/PageDown`، `Home/End`.
- لینک عمیق: `#scene-7` یا `#slide-3`.
- **Scale-to-fit**: هر صحنه با اندازه‌گیری ارتفاع/عرض واقعی و اعمال ضریب `scale`
  در هر اندازهٔ صفحه (موبایل تا دسکتاپ، پرتره و لندسکیپ) کامل جا می‌شود.

## پردهٔ ۲ — بخش تعاملی

- **کانال ویدیویی (اولین بخش پردهٔ ۲)**: تماشای ویدیوهای `@d-pay` **داخل خود سایت** —
  بدون ترک صفحه (جزئی‌ترین توضیح در بخش «کانال ویدیو و پخش درون‌سایتی»).
- **آزمایشگاه اوراکل**: محاسبه‌گر نمایشی معادل کریپتویی فاکتور دلاری با نرخ‌های
  شبیه‌سازی‌شده (برچسب «نمایشی»).
- **تب‌های یکپارچه‌سازی**: موکاپ تنظیمات ووکامرس + نمونهٔ کد `POST /order/add` و
  `POST /order/verify` با دکمهٔ کپی و پیمایش با کلیدهای جهت‌نما.
- **چک‌لیست راه‌اندازی ۸ قدمی**: ۴ مرحلهٔ ساخت فروشگاه (اسلاید ۴) + ۴ گام افزونهٔ ووکامرس
  (اسلاید ۵)؛ وضعیت در همان مرورگر ذخیره می‌شود.
- **پنل نمایشی پذیرنده**: موجودی، تاریخچهٔ سفارش‌ها، **خروجی CSV گزارش‌گیری** و
  **مودال برداشت دستی** با تایم‌لاین ثبت ← بررسی موجودی/شبکه/مبلغ ← قرارداد هوشمند
  ← ثبت روی بلاک‌چین (شبیه‌سازی).
- **جمع‌بندی** + خط «ماژول‌های اختصاصی» (دعوت به همکاری — عین متن اسلاید ۵) و «پخش دوبارهٔ ارائه».

## کانال ویدیو و پخش درون‌سایتی (`#media`)

مخاطب برای دیدن ویدیوها از سایت بیرون نمی‌رود؛ یک **پنجرهٔ پخش شناور** روی همان صفحه
باز می‌شود و تا وقتی کاربر خودش نخواهد، هیچ درخواستی به YouTube نمی‌رود.

### چیدمان (به‌ترتیب اولویت دیده‌شدن)

| جایگاه | چه کاری | چرا آنجا |
|---|---|---|
| ابتدای پردهٔ ۲ (`#media`) | هاب کامل کانال: پخش‌کننده + کارت کانال + فهرست ویدیوها | بعد از تمام‌شدن دک، توجه و کنجکاوی در اوج است و «دیدن = باورکردن» پیش از درخواست فنی (یکپارچه‌سازی) |
| صحنهٔ پایانی دک | دکمهٔ «ویدیوها و تیزر» | لحظهٔ خداحافظی با ارائه؛ بالاترین نرخ تبدیل به کلیک |
| کارت جمع‌بندی | «تیزر ۴۸ ثانیه‌ای» + «عضویت در کانال» | بعد از پاسخ به سؤالات، مخاطب آمادهٔ اقدام است |
| پیمایهٔ سایت | پیوند «ویدیوها» | دسترسی از هر بخش |
| تیزر یک‌باره (گوشهٔ صفحه) | کارت کوچک با پخش سریع | فقط یک بار روی هر دستگاه، بعد از ورود به پردهٔ ۲ |

### حریم خصوصی و نحوهٔ پخش

- **facade**: پوسترها از `i.ytimg.com` به‌صورت `data-lazy-src` و فقط وقتی بخش نزدیک دید
  بود لود می‌شوند؛ `iframe` هرگز قبل از کلیک ساخته نمی‌شود (صفر کوکی YouTube در بازدید اول).
- پخش از `https://www.youtube-nocookie.com/embed/<id>` با `rel=0`، `playsinline=1`،
  `iv_load_policy=3` و `playlist=<idهای کانال>` + `index=<i>` ⇒ «ویدیوی بعدی» در همان پنجره.
- پنجره **مودال نیست**: سایت پشتش زنده است؛ دکمهٔ اندازه (`sm/md/lg`)، انتقال به کنار دیگر
  صفحه، و «کوچک‌کردن» که صدا را قطع نمی‌کند (Esc در هر دو حالت پخش را می‌بندد).
- هر ویدیوی فهرست، پیوند اصلی `https://youtu.be/<id>` را به‌عنوان `href` دارد؛ با JS خاموش
  یا اگر ویدیویی Embed نشد، همان لینک کار می‌کند (progressive enhancement).
- وضعیت «دیده‌شد» و تنظیمات پنجره در `localStorage` می‌ماند (`dpay-yt-watched`, `dpay-yt-win`).
- **هاور = گرم‌کردن اتصال**: تنها وقتی نشانگر/فوکوس روی یک دکمهٔ «پخش» می‌رود،
  یک `<link rel="preconnect">` به `youtube-nocookie.com` تزریق می‌شود — شروع پخش سریع‌تر،
  بدون هیچ هزینه‌ای در بارگذاری اولیه (الگوی facade + preconnect-on-hover).
- داخل خود پنجرهٔ پخش هم پیوند «عضویت در کانال» و «کپی لینک ویدیو» نشسته است؛
  مخاطب همان‌جا که ویدیو را می‌بیند، کانال را سابسکرایب یا لینک را share می‌کند.

### افزودن ویدیوی جدید (بدون دست‌زدن به JS)

فهرست از DOM خوانده می‌شود؛ کافی است یک `li` در `#ytList` کپی و مقدارها را عوض کنید —
پلی‌لیست، دکمه‌های قبلی/بعدی، نوار ویدیوها و شمارش‌ها خودکار به‌روز می‌شوند:

```html
<li class="yt-item" data-yt="VIDEO_ID" data-title="عنوان" data-dur="0:59" data-cat="product" data-views="123">
  <a class="yt-thumb" href="https://youtu.be/VIDEO_ID" data-yt="VIDEO_ID" aria-label="پخش در همین سایت: عنوان">
    <img data-lazy-src="https://i.ytimg.com/vi/VIDEO_ID/hqdefault.jpg" src="data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7" alt="" width="480" height="360">
    <span class="yt-thumb__play" aria-hidden="true"></span>
    <span class="yt-thumb__dur">۰:۵۹</span>
  </a>
  …
</li>
```

`data-cat` در `product | news | other` (چیپ‌های فیلتر) و برای ویدیوهای خارج از موضوع ارائه
برچسب `pill wait` را هم کپی کنید. برای SEO، همان ویدیو را در `ItemList` داخل
`application/ld+json` هم اضافه کنید.

### تنظیمات

```js
window.DPAY_YT = {
  loopList : true,   // پلی‌لیست خودکار ویدیوهای کانال در همان پنجره
  autoplay : true,   // شروع پخش بلافاصله بعد از کلیک
  size     : 'md',   // اندازهٔ پیش‌فرض پنجره: sm | md | lg
  dock     : 'start',// کنار اولیه: start | end (در RTL: start = راست)
  channel  : 'https://www.youtube.com/@d-pay',
  deepLink : true    // ?yt=VIDEO_ID و #media/VIDEO_ID
};
```

- **لینک عمیق**: `index.html?yt=lh4Veu9mv-k` یا `#media/lh4Veu9mv-k` ⇒ همان ویدیو در همان
  لحظهٔ باز‌شدن، داخل سایت پخش می‌شود (قابل استفاده در توضیح ویدیوی یوتیوب، توییت و تلگرام).
- **API**: `DpayYT.open(index|id)`, `DpayYT.play(id)`, `DpayYT.next()`, `DpayYT.prev()`,
  `DpayYT.close()`, `DpayYT.minimize()`, `DpayYT.isOpen()`, `DpayYT.current()`,
  `DpayYT.watched()`, `DpayYT.list()`, `DpayYT.config`.
- **بدون API key**: برخلاف دستیار Gemini، این بخش به هیچ کلیدی نیاز ندارد و روی Google AI
  Studio و هر هاست استاتیکی کار می‌کند. تنها شرط، دسترسی مرورگر به `youtube-nocookie.com` است.
- هر ۷ ویدیوی موجود با oEmbed راستی‌آزمایی شدند و Embed آن‌ها فعال است.

## دستیار هوشمند و صوتی (Gemini) — اتصال در AI Studio

بخش «سؤالات متداول» و دکمهٔ شناور دستیار، به **Gemini** وصل می‌شوند. فایل
`assets/js/ai.js` خودش یک **سیستم مدیریت رفتار** است:

| کلید پیکربندی | پیش‌فرض | نقش |
|---|---|---|
| `model` | `gemini-2.5-flash` | مدل؛ در خطای مدل، خودکار به `gemini-2.0-flash` و `gemini-2.5-pro` می‌افتد |
| `systemInstruction` | ساخته‌شده در `systemPrompt()` | هویت، دامنه، ضدتزریق دستور، قواعد ارجاع به اسلاید |
| `persona` | `guide` | سه شخصیت: راهنمای صمیمی / رسمی / کوتاهِ صوتی |
| `strictGrounding` | `true` | پاسخ فقط از متن ارائه؛ خارج از آن: «در ارائه پوشش داده نشده» |
| `temperature` / `maxOutputTokens` | `0.35` / `700` | خلاقیت و حجم پاسخ |
| `safety` | `off` | حالت `strict` = BLOCK_LOW_AND_ABOVE روی چهار دستهٔ Harm |
| `voiceReplies` / `voiceRate` | `true` / `1` | پاسخ گفتاری (Web Speech TTS) و سرعت آن |

**اولویت خواندن:** DEFAULTS ← localStorage (`dpay-ai-settings`) ← تزریق بیرونی
`window.DPAY_AI_CONFIG` ← (کلید: `process.env.API_KEY` مخصوص بیلد AI Studio).

### اتصال در Google AI Studio
1. پروژه را به AI Studio بفرستید (App > Create > GitHub repo یا آپلود همین فایل‌ها).
   AI Studio روی Vite کلید را با `process.env.API_KEY` به کد تزریق می‌کند —
   `ai.js` همین را اولویت می‌دهد؛ هیچ تغییری لازم نیست.
2. اگر ساختید: **میکروفون** = `SpeechRecognition` مرورگر (Chrome/Edge فارسی را کامل
   پشتیبانی می‌کنند) و **گفتار** = `speechSynthesis`. CDN/فریم‌ورک اضافه نمی‌شود؛
   تنها درخواست شبکه‌ای که سایت می‌زند خودِ `generativelanguage.googleapis.com` است.

### کلید در هاست استاتیک (GitHub Pages و…)
دکمهٔ ⚙ داخل پنل دستیار → «کلید API» → ذخیره. کلید **فقط در localStorage همان
دستگاه** می‌ماند و در ریپو قرار نمی‌گیرد. برای امنیت، کلید را در Google Cloud با
HTTP Referrer محدود کنید. این سایت سمت‌کلاینت است؛ کلید برای کاربر قابل مشاهده می‌ماند
— برای محیط واقعی، کلید را پشت پروکسی مثل خود AI Studio نگه دارید.

### API برنامه‌ای
از هر جای صفحه: `DpayAI.open('سؤال شما')`، `DpayAI.ask(q)`، `DpayAI.config.model = ...`.
