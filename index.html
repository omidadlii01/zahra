REST API — order flow 
# 1 — create order
POST /order/add
{
  "amount": 20,
  "merchant_code": "dpay_live_9f27ac",
  "order_id": "ORD-1042",
  "callback": "https://shop.com/verify"
}
→ 200 · { "code": 20, "payment_url": "https://pay…/A91x" }

# 2 — buyer returns with Authority
GET {callback}?Authority="A91x_Q7"

# 3 — verify payment
POST /order/verify
{ "authority": "A91x_Q7" }
→ 20 paid · 13 failed · 21 duplicate
  1. 1
    POST /order/add: ارسال مبلغ، callback، شماره سفارش و merchant_code ← دریافت کد ۲۰ و لینک درگاه.
  2. 2
    هدایت خریدار به Callback: پس از پرداخت، درگاه خریدار را همراه کد اختصاصی Authority به آدرس Callback برمی‌گرداند.
  3. 3
    POST /order/verify: ارسال کد Authority جهت تایید نهایی درگاه (کد ۲۰ = پرداخت موفق، کد ۱۳ = ناموفق، کد ۲۱ = قبلا ثبت‌شده).
  4. ✦
    ماژول‌های اختصاصی: امکان توسعه ماژول‌های سفارشی توسط تیم فنی D-pay برای سیستم‌های اختصاصی.

  • گزارش‌گیری لحظه‌ای فروش‌ها: مشاهده کامل سفارش‌ها، تراکنش‌های موفق و تاریخچه درآمدها در پنل پیشرفته پذیرنده.
